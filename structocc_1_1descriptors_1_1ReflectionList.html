Detailed Description

The reflections the descriptor is built from.

Only one member of each Friedel pair is stored. Without anomalous dispersion F(-h) = conj(F(h)) exactly – the same floating point values, not merely the same to rounding – so intensities already carries the factor of two for the mate, and summing over this list is summing over the whole sphere.
