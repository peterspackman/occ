Eigen::Tensor< double, 4 > occ::qm::IntegralEngine::ao_direct_half_transform ( const Mat & C,
const Mat & Schwarz = Mat() ) const

AO-direct first-quarter MO transform.

Returns the half-transformed integrals H(i, ν, ρ, σ) = Σ_μ C(μ,i) (μν|ρσ) for the coefficient block C (nbf x nblk), streaming shell quartets with an inlined contraction so the full N⁴ tensor is never materialized. Used by AO-direct correlation methods; the inner loop is templated (not a std::function) for speed.

Restricted two-electron response for a batch of symmetric per-spin densities: jf * 2 J[D1] - kf * K[D1] for each, the last exchange_only of them without the Coulomb term.

One integral pass per chunk of densities, digested as small dense products over the whole chunk (density index fastest), so the cost per extra density is close to the arithmetic, not memory traffic. Used by CPHF.

Nuclear gradient (3 x natom) of the two-electron energy jf * E_J[D] + kf * E_K[D] where E_K is the full exact-exchange energy (negative), so a global hybrid passes kf = its exact-exchange fraction and Coulomb-only passes kf = 0.

◆ multipole_operator_grad()

std::vector< MatTriple > occ::qm::IntegralEngine::multipole_operator_grad ( Op op,
bool use_shellpair_list = true ) const

Multipole AO matrices with the gradient operator on the ket.

For op == Op::dipole libcint computes <φ_μ | r_α | ∇_β φ_ν> (9 components: α outer, β inner). For op == Op::quadrupole it computes <φ_μ | r_α r_β | ∇_γ φ_ν> (27 components: row-major (α,β) outer, γ inner). Returns one MatTriple per multipole component (3 for dipole, 9 for quadrupole), with the inner MatTriple holding the 3 spatial derivative components.

Use the chain rule ∂M_α(μ, ν, O=0)/∂R_(atom of ν)_β = - <φ_μ | M_α | ∂_β φ_ν> to convert these "ket-side" integrals to per-atom Cartesian gradients.
