Detailed Description

Three-centre integrals (μν|P) over the screened canonical shell pairs (q <= p, as IntegralEngine::shellpairs()), packed: one contiguous np x nq block per stored shell pair, every auxiliary function a column.

Pairs the shell-pair screen drops are never stored, and only one triangle is, so the store is a fraction of the dense nbf x nbf x naux one.

Under a byte budget only some pairs are stored – those most expensive to recompute per byte first – and unstored() lists the rest for the caller to compute directly. A complete store is folded with the Coulomb metric as soon as it is built, B = (μν|P) L^-T, so exchange and the correlated methods need no metric solve; a partial store keeps the raw integrals.
