◆ evaluate_basis_subset()

GTOValues occ::gto::evaluate_basis_subset ( const gto::AOBasis & basis,
Mat3NConstRef grid_pts,
int max_derivative,
const std::vector< int > & shell_indices )

Evaluate basis functions for a subset of shells, PACKED into a compact GTOValues whose columns span only those shells: phi is (npts x nbf_local) with nbf_local = sum of the subset's shell sizes, laid out in the order of shell_indices.

Pass shell_indices ascending so the local bf layout matches ascending global bf order (makes gather/scatter contiguous). Used for block-sparse DFT XC integration where most basis functions are negligible over a spatially-localized grid batch.
