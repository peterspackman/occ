Detailed Description

Per-point derivatives of Becke-partitioned weights.

For a point r attached to parent atom A with partitioned weight w, operator() fills dw (3 x natoms) with dw/dR_B for every atom B, the parent's column by translational invariance. Same partition (Becke cell function, Becke or Treutler-Ahlrichs size adjustment) as calculate_atomic_grid_weights.
