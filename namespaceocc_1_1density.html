◆ evaluate_orbitals_on_grid()

Mat occ::density::evaluate_orbitals_on_grid ( const occ::gto::AOBasis & basis,
MatConstRef C,
const occ::Mat3N & points )

Signed orbital amplitudes psi_i(r) = sum_mu C(mu, i) phi_mu(r) for each column of C, returned as an (npoints x ncols) matrix.

Uses the same AO values as the density evaluation, so the occupation weighted sum of psi_i^2 reproduces evaluate_density. Points are processed in parallel blocks, so memory stays bounded for large grids.
