Detailed Description

template<typename T>
class occ::ints::ESPEvaluator< T >

High-level ESP integral evaluator.

This class manages precomputed shell pair data and workspace buffers for efficient evaluation of ESP integrals over many grid points.

Usage: ESPEvaluator<double> esp(boys_table); esp.add_shell_pair(la, lb, na_prim, nb_prim, ...); esp.evaluate(shell_idx, grid_points, integrals, workspace);

The pair's integrals contracted as they are formed, for seminumerical exchange: with V as from evaluate_soa, G[(bf_q + b) * ld + i] -= sum_a F[(bf_p + a) * ld + i] V_ab(i) and, when both, G[(bf_p + a) * ld + i] -= sum_b F[(bf_q + b) * ld + i] V_ab(i) (a over the pair's first shell, b its second).

V is never stored in full. npts as for evaluate_soa, ld >= npts.

One pass over a Hessian pair, point-fastest like evaluate_soa: V[(k * nab + ab) * ldv + i], k = 0 the integrals (a b | 1/|r - x_i|), 1..3 their d/dA_{x,y,z}, 4..6 d/dB_{x,y,z}; and, unless W is null, second derivatives contracted with per-point weights, out[k] += sum_i sum_ab W[ab * ldw + i] d2/dc_k (a b | ...), 21 values: AA (xx, xy, xz, yy, yz, zz), AB (A_d B_e at 3 d + e), BB (as AA).

W must be zero on padding points.

One pass over a derivative pair giving both its integrals and their centre derivatives contracted with per-point weights: A[ab * lda + i] = (a b | 1/|r - x_i|) (nab rows, as evaluate_soa) out[c] += sum_i sum_ab W[ab * ldw + i] d/dc A_ab(x_i) c = A_x, A_y, A_z (and B_x, B_y, B_z when ncentres == 2).

The derivative integrals are never stored. W must be zero on padding points.

◆ pair_estimate()

template<typename T>
T occ::ints::ESPEvaluator< T >::pair_estimate ( size_t shell_idx) const

Grid-point-independent upper bound on this pair's ESP integrals, sum_prim |2 pi / p * c_a * c_b * exp(-mu R_AB^2)|, i.e.

the integral prefactor with the Boys factor F_0 <= 1 bounded out. Because it drops the only distance-to-grid-point dependence, it bounds the pair everywhere and is the right magnitude to screen a 1/R kernel on. Cheaper and tighter than the overlap, which is this times sqrt(pi/p)/2 and so understates compact pairs badly.

◆ pair_far_estimate()

template<typename T>
std::array< T, 2 > occ::ints::ESPEvaluator< T >::pair_far_estimate ( size_t shell_idx) const

Far-field form of the same bound, {q1, spread}: at a point C with R = |C - pair_center| > spread the pair's ESP integrals are at most q1 / (R - spread) (each primitive's F_0(T) <= sqrt(pi/T)/2).

The 1/R tail is kept: this only tightens the bound, it never cuts it off.
