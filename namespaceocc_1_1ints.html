Detailed Description

Effective core potential (ECP) integrals over Cartesian Gaussians.

The operator about an ECP centre C is

U(r) = U_L(r) + sum_{l<L} sum_m |lm> U_l(r) <lm|, U_l(r) = sum_k d_k r^(n_k - 2) exp(-zeta_k r^2),

with the local channel L the highest angular momentum on that centre and the channels below it stored as U_l - U_L (the BSE/Gaussian convention).

The local (type-1) term is a three-centre integral done analytically with McMurchie-Davidson Hermite expansions: r^0 is a plain three-Gaussian overlap, r^-1 reduces to Boys functions and r^-2 to the analogous G_m(T) = int_0^1 (1-v^2)^m exp(-T(1-v^2)) dv.

The semilocal (type-2) term uses the half-numerical scheme of Flores-Moreno et al., J. Comput. Chem. 27, 1009 (2006): each Gaussian is expanded about C in real spherical harmonics with the plane-wave expansion, the angular integrals are exact (tabulated from harmonic polynomials), and the radial integrals

int r^(N+n) exp(-zeta r^2 - a(r-|A|)^2 - b(r-|B|)^2) i~_la(2a|A|r) i~_lb(2b|B|r) dr

(i~ the exponentially scaled modified spherical Bessel function) are done per primitive triple with fixed-order Gauss-Legendre on a window placed around the peak of that integrand. The window depends smoothly on the geometry and the order is fixed, so the integrals are smooth functions of the nuclear positions.

There is no fixed angular momentum limit. Derivatives with respect to the basis centres come from shells with l raised or lowered (l +- 1, l +- 2) and exponent-weighted coefficients; derivatives involving C follow from translational invariance.
