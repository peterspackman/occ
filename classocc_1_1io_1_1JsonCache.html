Detailed Description

Somewhere to keep expensive intermediate results (monomer energies, wavefunctions, solvation surfaces) as JSON documents, so a repeat calculation can skip them.

A key names one document. The file backend uses it as the path, so the keys are the cache filenames the calculations have always written; the memory backend only needs them to be distinct. Checking that a cached document still matches the calculation (model, level of theory, ...) is the caller's job: the cache just stores what it is given.
