First derivatives with respect to the basis centres, C held fixed.

out[0..2] = d/dA_{x,y,z}, out[3..5] = d/dB_{x,y,z}; each block row-major ncart(la) x ncart(lb). Blocks not requested are left untouched.

Second derivatives with respect to the basis centres, C held fixed.

aa: xx,xy,xz,yy,yz,zz on A; ab: 3*i + j with i on A and j on B; bb: as aa on B. Blocks not requested are left untouched.
