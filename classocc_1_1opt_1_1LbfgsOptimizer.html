Detailed Description

L-BFGS geometry optimizer in Cartesian coordinates.

Ported from klasp: the two-loop recursion with H0 = (s.y / y.y) I from the latest pair (or a model Hessian, see LbfgsSettings::precondition), pairs with y.s <= 0 skipped and a fall back to steepest descent (history cleared) when the direction goes uphill. In place of a line search the step is scaled to a trust radius on the largest atomic displacement. Convergence is checked with the same per-atom criteria as GeometryOptimizer.
